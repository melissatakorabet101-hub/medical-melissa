🆘 Centre d’aide du praticien

Voici le guide rapide pour utiliser MedicalMelissa correctement.

1. Ajouter un patient

Clique sur Ajouter un patient, remplis l’heure, le nom, le genre, la date de naissance, le motif et le statut, puis clique sur Enregistrer le patient.

2. Gérer les rendez-vous

Va dans Rendez-vous, ajoute l’heure, le type de consultation et la disponibilité. Tu peux aussi modifier ou supprimer un créneau.

3. Gérer les dossiers

Dans Dossiers médicaux, choisis un patient, complète le diagnostic, le traitement, la date de dernière visite et les notes, puis enregistre.

4. Gérer les factures

Dans Factures, saisis le prix complet, le montant versé et l’échéance. Le reste à payer est calculé automatiquement.

Astuce :

Tu peux modifier ou supprimer un patient, un rendez-vous ou une facture directement depuis leur tableau. Les données restent enregistrées dans le navigateur.
